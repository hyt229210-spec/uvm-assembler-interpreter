
# Ассемблер и интерпретатор учебной виртуальной машины

Практическая работа №3 по дисциплине
«Конфигурационное управление».

Вариант №4.

## 1. Общее описание

Проект предназначен для разработки ассемблера
и интерпретатора учебной виртуальной машины (УВМ).

Ассемблер принимает программу в формате YAML,
проверяет правильность команд и преобразует
их во внутреннее представление.

Проект реализуется на языке Python.

## 2. Поддерживаемые команды

| Команда | Код A | Операнд | Размер |
|---|---:|---|---:|
| load_const | 6 | value | 5 байт |
| load | 80 | offset | 2 байта |
| store | 5 | address | 4 байта |
| ror | 123 | address | 4 байта |

### Описание команд

- load_const — загрузка константы в аккумулятор.
- load — чтение значения из памяти по адресу,
  вычисляемому как сумма аккумулятора и смещения.
- store — запись значения аккумулятора в память
  по указанному адресу.
- ror — побитовый циклический сдвиг вправо.

### Ограничения операндов

- load_const: от 0 до 67108863.
- load: от 0 до 63.
- store: от 0 до 4194303.
- ror: от 0 до 4194303.

## 3. Формат входной программы

Входные программы записываются в формате YAML.

Пример:

```yaml
program:
  - command: load_const
    value: 466

  - command: load
    offset: 53

  - command: store
    address: 586

  - command: ror
    address: 683
```

Каждая команда содержит название и необходимый
операнд.

## 5. Установка

Для работы необходим Python 3.14 или совместимая
версия Python 3.

Создание виртуального окружения:

```bash
py -m venv .venv
```

Установка зависимостей в Windows:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 6. Запуск ассемблера

В Windows:

```powershell
.\.venv\Scripts\python.exe src/assembler.py examples/specification.yaml output.bin --test
```

Параметры:

- input — путь к исходному YAML-файлу.
- output — путь к выходному бинарному файлу.
- --test — вывод внутреннего представления программы.

На первом этапе реализована трансляция
в промежуточное представление.
Формирование бинарного файла будет добавлено
на втором этапе.

## 7. Запуск тестов

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют:
- перевод всех четырёх команд;
- обработку неизвестных команд;
- проверку диапазонов значений;
- обработку некорректных YAML-структур;
- обработку отсутствующих операндов;
- отклонение пустых программ.

## 8. Запуск интерпретатора

Интерпретатор принимает следующие аргументы:

- input — путь к бинарной программе;
- dump — путь к JSON-файлу дампа памяти;
- start — начальный адрес памяти;
- end — конечный адрес памяти.

Пример запуска в Windows:

```powershell
.\.venv\Scripts\python.exe src/interpreter.py memory_copy.bin memory_dump.json 100 202
```
